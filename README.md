# Библиотека книг (бинарное дерево + SQLite)

Консольное приложение на Python. Каталог книг:

- **хранится постоянно** в базе **SQLite** (файл `library.db` в папке проекта);
- **обрабатывается** в **бинарном дереве поиска** по номеру **УДК** (требование задания);
- **отображается** в отчёте с сортировкой **по году издания** (запрос к SQLite).

## Возможности программы

| Функция | Описание |
|--------|----------|
| Начальное заполнение | При первом запуске создаётся `library.db` и загружается демонстрационный каталог |
| Добавление | Книга сохраняется в SQLite и вставляется в BST по УДК |
| Удаление | Запись удаляется из базы и из дерева |
| Отчёт | Список всех книг из базы, `ORDER BY year` |
| Сохранение между запусками | Все изменения остаются в `library.db` после закрытия программы |
| Поиск | Поиск книги по номеру УДК в бинарном дереве |

### Поля книги

- Номер УДК (первичный ключ в SQLite и ключ BST)
- Фамилия и инициалы автора
- Название
- Год издания
- Количество экземпляров в библиотеке

### Структура проекта

```
BookLibrary/
  main.py           # Точка входа
  cli.py            # Консольное меню
  book.py           # Модель книги
  book_tree.py      # Бинарное дерево поиска (в памяти)
  database.py       # Работа с SQLite
  library.py        # Связка базы и дерева
  library.db        # Файл базы (создаётся при первом запуске)
  README.md
```

## База данных SQLite

### Что используется

- СУБД: **SQLite 3** (модуль `sqlite3` входит в Python, отдельно ставить не нужно).
- Файл: **`library.db`** в корне проекта (рядом с `main.py`).
- Таблица: **`books`**

| Поле | Тип | Описание |
|------|-----|----------|
| `udc` | TEXT, PRIMARY KEY | Номер УДК |
| `author` | TEXT | Автор |
| `title` | TEXT | Название |
| `year` | INTEGER | Год издания |
| `copies` | INTEGER | Количество экземпляров |

### Как данные проходят через программу

1. **Старт** — `database.py` создаёт таблицу; если база пустая, записывается начальный набор книг.
2. **Загрузка** — все строки из SQLite читаются в **бинарное дерево** (`library.py`).
3. **Добавить / изменить** — сначала `INSERT`/`UPDATE` в SQLite, затем вставка в BST.
4. **Удалить** — удаление из BST, затем `DELETE` в SQLite.
5. **Отчёт по годам** — выборка из SQLite: `ORDER BY year, udc`.
6. **Закрытие программы** — файл `library.db` остаётся на диске; при следующем запуске каталог поднимается из базы.

### Просмотр базы вручную (по желанию)

В cmd из папки проекта:

```text
sqlite3 library.db
```

В консоли SQLite:

```sql
.tables
SELECT * FROM books ORDER BY year;
.quit
```

Утилита `sqlite3` есть не на всех системах Windows; для учебного просмотра достаточно самой программы или расширения SQLite в VS Code.

### Сброс каталога

- Пункт меню **«Загрузить начальные данные»** — очищает таблицу и снова записывает демонстрационные книги.
- Либо удалите файл `library.db` и запустите `python main.py` — база создастся заново с начальным набором.

## Полная инструкция по развертыванию (Windows)

### Шаг 1. Скопировать проект

1. Склонируйте репозиторий или скопируйте папку в любое удобное для вас место, например:
   - `C:\Users\USER\Documents\GitHub\BookLibrary`
2. Правой кнопкой мыши по архиву, **Извлечь все…** в нужную папку.
3. Проверьте наличие `main.py`, `database.py`, `library.py`, `cli.py`, `README.md`.

### Шаг 2. Открыть проект в VS Code

1. Запустите **Visual Studio Code**.
2. **Файл** → **Открыть папку…** → выберите `BookLibrary`.
3. Терминал: **Терминал** → **Создать терминал**.

### Шаг 3. Создать venv

```text
python -m venv venv
```

### Шаг 4. Активировать venv

```text
venv\Scripts\activate
```

### Шаг 5. Запустить программу

```text
python main.py
```

При **первом** запуске в папке появится файл **`library.db`** с таблицей и начальными книгами.

## Как пользоваться консольным меню

После запуска отображается меню:

| Пункт | Действие |
|-------|----------|
| 1 | Показать каталог (сортировка по году издания) |
| 2 | Добавить книгу (ввод всех полей по запросу) |
| 3 | Удалить книгу по номеру УДК |
| 4 | Отчёт по годам (статистика и полный список) |
| 5 | Найти книгу по УДК в бинарном дереве |
| 6 | Загрузить начальные данные (с подтверждением) |
| 0 | Выход |

При добавлении книги с уже существующим УДК запись в базе обновляется.

## Повторный запуск

```text
venv\Scripts\activate
python main.py
```

## Устранение неполадок

| Проблема | Решение |
|---------|---------|
| `python` не найден | Установите Python с **Add to PATH** или используйте `py -3` |
| Ошибка доступа к `library.db` | Закройте другие программы, открывшие файл; проверьте права на папку |
| Нужен «чистый» каталог | Удалите `library.db` и запустите программу снова |

| Отчёт по году | `LibraryDatabase.get_books_sorted_by_year()` |
